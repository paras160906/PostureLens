Rule ID

CKV_DOCKER_1

Container running as root

Running a container as root gives the container full administrative privileges on the host system, which could lead to a complete system compromise if the container is breached.

12 RUN apt-get update && apt-get install -y curl
13 USER root // Vulnerable line
14 COPY . /app
build

Remediation

Ensure that the last USER instruction in the Dockerfile is not 'root'. Create a dedicated user group and user, then switch to it.
